
# Quiz Studio - Python Quiz App

A modern desktop quiz application developed using Python
and CustomTkinter.

## Features

- Orange, beige, and ivory themed UI
- 60 Python multiple-choice questions
- Three difficulty levels
- Beginner: 20 questions
- Intermediate: 20 questions
- Advanced: 20 questions
- Difficulty-based countdown timer
- Random question ordering
- Automatic score calculation
- Correct and incorrect answer highlighting
- Vertical scrolling
- Fixed navigation buttons
- Progress tracking
- Accuracy calculation
- Final results screen
- Restart and Play Again functionality

## Difficulty Levels

| Level | Questions | Time per Question |
|---|---|---|
| Beginner | 20 | 30 seconds |
| Intermediate | 20 | 45 seconds |
| Advanced | 20 | 60 seconds |

## Technologies Used

- Python
- CustomTkinter
- JSON
- Object-Oriented Programming
- Git and GitHub
